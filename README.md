# Healthy Pets - Clínica Veterinaria

Una landing page moderna y profesional para una clínica veterinaria, diseñada para presentar servicios, valores de la institución, testimonios y un formulario de citas que se integra con WhatsApp para facilitar la comunicación con los pacientes.

## 🐾 Descripción del proyecto

Healthy Pets es un sitio web informativo y visualmente atractivo para una clínica veterinaria. Su objetivo principal es brindar una experiencia clara y confiable a los usuarios que desean conocer los servicios disponibles, agendar citas y contactar rápidamente a la clínica.

El proyecto está pensado para transmitir confianza, cercanía y profesionalismo, destacando aspectos como:

- Atención veterinaria general y especializada
- Servicios preventivos y médicos
- Comunicación directa vía WhatsApp
- Diseño responsive para dispositivos móviles y escritorio

## ✨ Características principales

- Diseño moderno y limpio con una identidad visual amable
- Sección de inicio con mensaje de bienvenida y llamado a la acción
- Presentación de servicios veterinarios destacados
- Área de testimonios para reforzar la confianza del usuario
- Formulario de agendamiento de citas con integración a WhatsApp
- Compatibilidad con navegadores modernos y dispositivos móviles

## 🚀 Instalación y uso

No se requieren dependencias complejas para ejecutar este proyecto.

### Pasos básicos

1. Clona este repositorio:
   ```bash
   git clone https://github.com/tu-usuario/healthy-pets-clinica.git
   ```

2. Entra a la carpeta del proyecto:
   ```bash
   cd healthy-pets-clinica
   ```

3. Abre el archivo `index.html` en tu navegador, o usa una extensión como Live Server en Visual Studio Code.

> Nota: Si deseas agregar más funcionalidades, puedes ampliar el proyecto con un backend, base de datos o un sistema de reservas más robusto.
